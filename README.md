# Hasindu Nagolla Portfolio

Personal portfolio website for Hasindu Nagolla, an Intern Software Engineer focused on full-stack development, AI/ML, cloud infrastructure, and reliable software solutions.

## Tech Stack

- React
- Vite
- Tailwind CSS
- React Router
- Lenis

## Development

```bash
npm install
npm run dev
```

## Production Build

```bash
npm run build
npm run preview
```
